SawDust

A woodworking design tool for Windows

SawDust is a desktop app for designing home woodworking projects. You describe a piece as boards, panels and joints, with dimensions that can be expressions of a few named parameters, and SawDust produces the shop outputs from that: cut lists with cost estimates, sheet-goods layouts, dimensioned shop drawings, assembly steps, DXF files for a CNC router, and part labels.

An optional AI Apprentice can draft a design from a photo or a description and edit the open project by conversation. It runs on your own Anthropic API key, so nothing is sent anywhere unless you connect it.

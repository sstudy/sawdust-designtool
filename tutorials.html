Video Tutorials

A bedside cabinet, start to finish

The training video builds one bedside cabinet in SawDust from an empty project to the cut list, sheet layout, shop drawings and part labels you take to the bench. It is one continuous build in twelve chapters, and each chapter stands on its own: the chapter list below jumps straight to any of them. The same video is what Help → Video Tutorials opens from inside the app.

Watch on YouTube: SawDust tutorial: design a bedside cabinet from scratch · 41 minutes · the SawDust tutorials playlist · the SawDust Design Tool channel.

Following along

Everything in the video is in the release build of SawDust, with the user manual covering each feature in more depth. Chapter 7 uses the optional AI Apprentice, which needs your own Anthropic API key; the rest of the build does not.

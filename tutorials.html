A bedside cabinet, start to finish

The training video builds one bedside cabinet in SawDust from an empty project to the cut list, sheet layout, shop drawings and part labels you take to the bench. Watch it as one continuous build, or go straight to a chapter: each chapter is also its own short video, and each stands on its own. Everything in the video is in the release build of SawDust, with the user manual covering each feature in more depth. Chapter 7 uses the optional AI Apprentice, which needs your own Anthropic API key; the rest of the build does not.

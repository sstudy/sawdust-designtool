Privacy Policy

Effective date: 17 September 2026
Applies to: SawDust — A Woodworking Design Tool, version 6.0 and later, for Windows

SawDust is a desktop design tool. It has no accounts, no sign-in, and no SawDust-operated server. Your designs stay on your computer. The one feature that sends design data anywhere is the optional AI Apprentice, and it sends that data to Anthropic, using an API key that you supply, only when you use it.

What SawDust does not do

  • It does not collect, transmit, or sell personal information to the developer or to anyone else.
  • It does not send usage analytics or crash reports over the network.
  • It does not create a user, device, or install identifier.
  • It does not contain advertising or third-party tracking.
  • It does not check for updates itself. Updates arrive through the Microsoft Store.

Data that stays on your computer

SawDust stores the following on your own machine. None of it is uploaded by the app.

  • Your designs (.swdt files), wherever you save them, along with small companion files beside each design: the AI Apprentice chat transcript, the project change log, view settings, and any reference photos you attach.
  • Settings, in your local application data folder (%LOCALAPPDATA%\SawDust): window layout, recently opened files, your materials library, shop options, stock presets, and any templates you save.
  • Crash-recovery copies of unsaved work, in the same folder, so a design can be restored after an unexpected exit.
  • A diagnostic log (sawdust.log), in the same folder. It records application events and error details, which can include file names and paths. It is never transmitted. If you contact support you may choose to share it, and that choice is yours.

Uninstalling SawDust does not delete your designs. You can delete any of the files above at any time.

The AI Apprentice (optional)

The AI Apprentice is off until you connect it. It works only with your own Anthropic API key, and requests go directly from your computer to Anthropic's API. They do not pass through any server operated by the developer of SawDust, and the developer never receives them.

If you never enter an API key, SawDust sends nothing to Anthropic.

When you have connected a key:

  • Opening the Apprentice panel makes one request to Anthropic to confirm that the key works. That request contains no design data.
  • Sending a message transmits to Anthropic:
    • the text you typed;
    • any photo you attached to that message, or chose when starting a design from a photo;
    • a description of the design you have open: its file name (not its folder path), the project name and notes, parameters, materials and their costs, every part with its dimensions and position, joints, groups, layers, hardware, and the names and captions of attached reference images;
    • the results of any reports the Apprentice requests while working, such as the cut list, sheet layout, hardware list, or design checks;
    • today's date and your display unit.

Anthropic processes this data under its own terms and privacy policy, and bills you directly for API usage. Review Anthropic's policies at anthropic.com before using the feature. Do not include information in a design's name or notes, or in a photo, that you would not want sent to Anthropic.

Your API key is stored on your computer in encrypted form, protected by Windows for your user account (DPAPI). Alternatively, SawDust reads it from the ANTHROPIC_API_KEY environment variable. The key is sent only to Anthropic. It is never written to the log.

Chat transcripts are saved beside your design so you can read them later. A saved transcript is not re-sent to Anthropic when you reopen the design, because each session starts a new conversation.

Microsoft Store purchases and the free trial

If you install SawDust from the Microsoft Store, the app asks Windows whether your copy is a trial, an expired trial, or a purchased copy. When you choose to buy, SawDust opens the Microsoft Store's own purchase window. Payment is handled entirely by Microsoft. SawDust never sees or stores your payment details, your Microsoft account, or your address. Microsoft's handling of that information is covered by the Microsoft Privacy Statement.

Diagnostic reporting

SawDust does not transmit diagnostics. The app contains a developer diagnostic option that can forward application events to a server address. It is inactive unless someone manually creates a configuration file on the computer naming that address; SawDust never creates this file, no address ships with the app, and there is no such file on a Store installation.

Children

SawDust is a general-purpose design tool and is not directed at children. It does not knowingly collect personal information from anyone, including children.

Changes to this policy

If a future version of SawDust changes what data leaves your computer, this policy will be updated before that version is released, and the effective date above will change.
